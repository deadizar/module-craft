FVTT module v13

## La Sombra de la Reina de los Dragones (v3.1.4 · Foundry v13)

### Instalación

1. En Foundry VTT: **Configuración → Módulos complementarios → Instalar módulo**.
2. Pega esta URL de manifiesto y pulsa **Instalar**:

   ```
   https://raw.githubusercontent.com/deadizar/module-craft/main/rolbaton-adventure-sombra-reina-dragones/module.json
   ```

3. Requiere Foundry v13 y dnd5e ≥ 5.0.
4. En el mundo, activa el módulo, abre el compendio de Aventura e impórtalo marcando «Mantener IDs».
